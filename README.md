# ncccl
英伟达集合通信库nccl的优化与分析

本项目基于nccl v2.29.2‑1版本

nccl是英伟达的集合通信库，旨在解决分布式训练场景下，多gpu协同工作的问题。

其实质并不是分布式通信，而是协调资源。在host侧，gpu是资源，协议是资源，网络是资源；在kernel侧，内存是资源，线程是资源。

如何给不同的操作匹配出最优的资源的组合，这是nccl要解决的最重要的问题。

随着gpu和不同通信方式的发展，nccl在最初版本的基础上，不断地进行迭代，但是原有的架构和设计已经不再适合现在的场景，我相信，在未来，nccl所要做的是，在一个动态平衡的系统中，解决熵增熵减的问题。

本项目尝试在原有代码的基础上，做出总结和优化，以帮助更多同学。
